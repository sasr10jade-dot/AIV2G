설치되었어요

홈 화면의 'AI-V2G' 아이콘으로 열 수 있어요.
앱 열기

아이폰은 사파리에서 3단계로 설치해요

  1. 화면 아래(또는 위)의 공유 버튼(네모에 위쪽 화살표)을 눌러요.
  2. 목록을 내려 '홈 화면에 추가'를 눌러요.
  3. 오른쪽 위 '추가'를 누르면 끝이에요.
카카오톡·네이버 앱 안에서 열었다면 오른쪽 아래 메뉴에서 'Safari로 열기'를 먼저 눌러 주세요.

브라우저 메뉴에서 설치해요

  1. 오른쪽 위(삼성 인터넷은 아래) 메뉴(⋮ 또는 ≡)를 눌러요.
  2. '앱 설치' 또는 '홈 화면에 추가'를 눌러요.
카카오톡·네이버 앱 안에서 열었다면 '다른 브라우저로 열기'(크롬·삼성 인터넷)를 먼저 눌러 주세요.
