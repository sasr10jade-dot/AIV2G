핵심 요약

아래 상세 카드들의 결과를 한 장으로 압축한 요약입니다. 자세한 근거는 각 카드에서 확인할 수 있습니다.

대시보드 이용 가이드

1. 핵심 요약

화면 맨 위 ★ 핵심 요약 카드는 아래 상세 카드들의 결과를 한 장으로 압축해서 보여줍니다 — 피크 저감률, 전력비용 절감액, 피크 시간대 충전 비중(적용 전→후), 최근 5일 재생에너지 비중, DR 이벤트 대응 실적입니다. 여기 나온 숫자는 전부 아래 해당 카드에서 그대로 가져온 값이며, 근거를 자세히 보려면 그 카드로 가면 됩니다.

2. 시나리오 설정

화면 상단 "시나리오" 카드에서 실증 규모와 최적화 조건을 바꿔가며 결과를 비교할 수 있습니다.

  • 프리셋 버튼 — 자주 쓰는 조합을 한 번에 적용하고 즉시 재계산합니다. 기본(EV 30대·21주), 실증 확대(EV 100대), 짧은 관측기간(4주), 보수적 SOC(60%)가 있습니다.
  • EV 대수 / 충전기 대수 / 관측기간(주) — 합성 시나리오의 실증 규모입니다. 관측기간이 길수록 데이터 건수와 계산 시간이 늘어납니다(최소 4주).
  • 목표 SOC(%) — 최적화가 세션 종료까지 채우려는 목표 충전량입니다. 낮출수록 과충전을 방지하는 보수적인 운영을 시뮬레이션합니다.
  • 최대충전/방전출력(kW), 예비 SOC(%) — V2G 최적화 엔진의 물리적 제약입니다. 예비 SOC 이하로는 방전하지 않습니다.
  • 시나리오 실행 버튼을 눌러야 위 값들이 반영되어 전체 파이프라인(데이터 생성→최적화→예측→재학습)이 다시 계산됩니다 — 수 초 정도 걸립니다.
  • 실증 데이터가 업로드된 상태에서는 EV/충전기 대수·관측기간 입력이 비활성화됩니다(규모는 실제 데이터가 결정). 최적화 파라미터만 계속 적용됩니다.

3. 화면 상단 정보

  • 데이터 소스 배지 — "데모 시나리오"는 합성 데이터, "실증 데이터"는 업로드된 실제 데이터를 사용 중임을 뜻합니다.
  • 갱신 시각 — 마지막으로 계산이 완료된 시각입니다.
  • 🌙/☀️ 테마 전환 — 다크모드(초승달 아이콘)와 일반모드(태양 아이콘)를 전환합니다. 기본값은 다크모드이며, 선택한 테마는 이 브라우저에 저장되어 다음 방문에도 유지됩니다.
  • 새로고침 — 시나리오 값은 그대로 두고 동일 조건으로 다시 계산합니다.
  • 가입 승인 — 모바일 가입 신청을 승인·반려하는 화면(17장)으로 이동합니다.
  • ▶ 자동 새로고침 — 켜면 5초마다 화면을 자동으로 다시 불러옵니다. 데이터는 전일 수집분의 익일 배치 기준이며, 실시간 수집·제어는 하지 않습니다.

4. KPI 요약 타일

  • 실증 데이터(연차별) — 사업수행계획서 v1.0 성과지표입니다. 1건 = 연계 충전기의 유효 충전 세션 1건 또는 차량-일 프로파일 1건이며, 1차년도(2026.11.1.~2027.4.15.) 4,000건·2차년도(2027.5.1.~11.30.) 4,500건 이상을 연차별로 겹치지 않게 셉니다. 공백기·사업기간 밖 데이터와 합성(모의) 데이터는 실적에 넣지 않고, 공개 데이터(전력수요·기상)는 참고 건수로만 봅니다. 방전은 실측이 아닌 추론이라 세지 않습니다.
  • 실증 EV / 실증 충전기 — 현재 시나리오의 차량·충전기 규모입니다.
  • 충전기 가동률(혼잡도) — 시간대별 "그 시간에 세션이 걸쳐 있는 충전기 수 / 전체 충전기 수"의 평균·피크값입니다. 피크가 높은 시간대는 충전 인프라가 부족할 수 있다는 신호입니다.
  • 활성 예측모델 — 현재 서빙 중인 수요예측 모델의 버전과 홀드아웃 MAE(평균절대오차, 작을수록 정확)입니다.

5. AI 적용 전·후 효용성 검증

계획서 4.1 다. "EV 30대 기반 V2G 타당성 검증"의 비교 관점을 그대로 보여줍니다 — 같은 실측 데이터에서 일반 충전(연결 즉시 충전)과 AI 최적화 적용을 비교한 피크 시간대 충전 비중, 충전 비용, 목표 배터리 도달률, AI 추론 V2G 예측률입니다. 피크 시간대는 날짜별 계통 전력수요 상위 25% 시간입니다. 아래 표는 같은 산식을 충전 시작 시간대·평일/주말·시작 SOC·전력수요 수준별로 나눠 계산한 조건별 반복 분석입니다. 적용 후 값은 추론 결과이며 실제 방전이 아닙니다.

6. 일반 충전 vs AI-V2G 최적화 차트

최근 5일 구간의 시간당 집계 충전부하(kW)를 비교합니다. 구리색은 AI 개입 없는 일반 충전(피크가 뾰족하게 튐), 틸색은 AI-V2G 최적화 적용 후(부하가 평탄화됨)입니다. 구리색이 틸색보다 높은 구간(=AI가 피크를 깎아낸 부분)은 옅은 초록 음영으로 강조됩니다. 마우스를 그래프 위에 올리면 해당 시각의 두 값을 함께 볼 수 있습니다. 차트 아래에는 "규칙기반(무제어) 대비 전력비용 절감액·절감률"이 함께 표시됩니다.

🤖 AI 방전 계획 설명 받기 — 차량 ID를 입력(비우면 방전량이 가장 큰 세션 자동 선택)하면 그 차량의 실제 최적화 스케줄(언제 충전/방전해서 얼마 버는지)을 Gemini가 자연어로 설명합니다. "차주(사용자)가 자기 차 계획만 보는 화면"의 최소 구현입니다 — 표시되는 숫자는 전부 실제 LP 최적화 결과이며 지어낸 값이 아닙니다.

7. 도시 전력수요 vs 재생에너지 발전 현황

최근 5일 구간의 도시 전력수요(MW)와 재생에너지(태양광 위주) 발전량(MW)을 함께 보여줍니다 — 바로 위 최적화 차트와 아래 이익공유 카드가 참조하는 전력가격·DR 신호가 어떤 배경 데이터로 만들어지는지 보여주는 카드입니다. 수요가 높고 재생에너지가 부족한 시간대일수록 가격이 오르고, AI-V2G는 그 시간대에 더 강하게 방전하도록 유도됩니다.

이 카드의 재생에너지 발전량은 항상 합성값입니다 — 실증 데이터를 업로드하거나 KPX SMP 가격 연동을 써도 이 값은 갱신되지 않습니다. 실제 재생에너지 발전량 공공데이터를 별도로 연계하기 전까지는 참고용으로만 보세요.

8. 이익공유 시뮬레이터

바로 위 차트에서 계산된 "규칙기반 대비 전력비용 절감액"을 차주·충전인프라 운영자·플랫폼 사업자 세 주체가 어떻게 나눠 가질 수 있는지 시뮬레이션합니다. 세 비율의 합이 100%가 아니면 계산되지 않습니다. 아직 실제 정산·포인트 지급 체계는 없고, PRD 1차년도 "이익공유 모델 경제성 분석 기초자료"를 위한 배분 구조 시험용입니다.

9. ㈜아크릴 예측모델 연계

계획서상 AI 예측모델(충전수요·전력수요·가용자원)은 참여기관 ㈜아크릴이 개발해 일 배치로 보내 줍니다. 예측 결과가 수신되면 전망·충전 추천에 우선 쓰이고, 그 전까지는 이 시스템의 기준(비교용) 모델로 계산합니다. 학습용 정제 데이터 제공과 수신 현황은 웹앱 관리(/admin)의 "㈜아크릴 연계" 탭에서 확인합니다.

10. AI 수요예측: 실측 vs 예측

모델이 학습 때 보지 않은(홀드아웃) 최근 5일의 실제 충전수요와 AI 예측치를 비교합니다. 두 선 사이 회색 음영이 "오차 폭"입니다 — 넓을수록 그 시점의 예측이 실측과 많이 벌어졌다는 뜻이며, 카드 상단에 구간 전체의 평균오차(MAE)가 표시됩니다.

11. AI 수요예측 전망 (일별/주별/월별)

미래 구간을 재귀 예측(recursive forecasting)으로 전망합니다 — 일별(시간대별)은 다음 48시간, 주별은 다음 4주(일 합계), 월별은 다음 약 6개월(주 합계)을 보여주며, 기간이 길어질수록 오차가 누적되는 추세 전망입니다. 예측선 주위의 옅은 음영은 그 누적 오차를 근사한 "불확실 구간"으로, 멀리 볼수록(특히 월별) 넓어집니다 — 통계적으로 보증된 신뢰구간은 아니고 감을 잡기 위한 참고용입니다.

12. 차량별 배터리·충전 현황 (OBD)

예측 차트들 아래 표에 등록된 모든 차량의 가장 최근 OBD 상태(요약 스냅샷, 시계열 전체가 아님)를 보여줍니다 — 차량 ID·차종·SOC(%)·상태(주행중/충전중/연결·대기/미접속)·충전 전력(kW, 최근값)·배터리용량·배터리온도·V2G 방전가능(kWh)·V2G 지원 여부·마지막 업데이트 시각입니다. 실증 데이터가 업로드되면 그 실제 값으로, 아니면 데모 시나리오 값으로 표시됩니다. SOC가 20% 미만이면 빨간색, 90% 초과면 초록색, 배터리온도가 45°C 초과면 빨간색으로 강조됩니다. 기본은 높이가 제한된 스크롤 목록이며, 표 우측 상단 "펼치기" 버튼을 누르면 스크롤 없이 전체 차량을 한 번에 볼 수 있습니다.

"V2G"와 "V2G 방전가능(kWh)"은 다른 기준입니다 — V2G 열은 그 차종 자체가 그리드 역송전을 지원하는지(5개 차종 중 2종만 가능, 나머지는 상태와 무관하게 항상 불가)를 뜻하고, V2G 방전가능(kWh) 열은 최근 기록 기준으로 방전 가능하다고 추론되는 양(모의)입니다. 아래 4가지 조건을 모두 만족해야 0보다 큰 값이 나옵니다 — ① 차종이 V2G 가능, ② 충전기에 연결됨, ③ 주행 중이 아님, ④ SOC가 안전 구간(35~80%) 안. 이 기준은 실제 AI-V2G 최적화(LP)가 방전을 허용하는 조건과 동일합니다 — 표에 "방전 가능"으로 보이는 차량은 실제로도 디스패치될 수 있는 차량이라는 뜻입니다.

표 아래 "충전 효율(추정)"은 차량(OBD) 충전량과 충전기 계측 충전량을 비교한 값입니다 — 두 데이터를 연결할 ev_id가 있는 세션만 대상이며, 지금은 합성 데이터에서만 의미 있는 값이 나옵니다(실측 데이터는 OCPP id_tag-ev_id 매핑이 확보돼야 채워집니다).

13. 실제 실증 데이터 연동 (참고)

현재 화면에는 업로드 버튼이 없어, API로 직접 연동합니다. 스키마 검증을 통과한 CSV만 반영되며, 반영되는 즉시 이 대시보드와 예측·최적화 API가 자동으로 해당 데이터를 사용합니다.

curl -X POST http://localhost:8000/ingest/upload \
  -F "ev_telemetry=@ev_telemetry.csv" \
  -F "charger_sessions=@charger_sessions.csv" \
  -F "grid_signal=@grid_signal.csv"
  • GET /ingest/status — 현재 데모/실증 모드 확인
  • DELETE /ingest/upload — 업로드된 데이터를 지우고 데모 모드로 복귀

14. 계정 · 권한

로그인은 2단계 권한으로 나뉩니다 — 최고관리자는 계정 생성·삭제(우측 상단 "계정관리")를 포함한 모든 기능을, 관리자는 시나리오 실행·데이터 제공 등 일반 운영 기능을 사용할 수 있습니다. 계정관리 버튼은 최고관리자로 로그인했을 때만 보입니다.

차량 등록자(이용자) 계정으로 로그인하면 이 대시보드가 아니라 모바일 앱(/app)으로 이동합니다 — 운영 데이터와 다른 차량 정보는 볼 수 없습니다.

15. 모바일 가입 승인

모바일 앱에서 회원가입한 이용자는 승인 대기로 등록되며, 관리자가 승인해야 차량이 연결되어 알림·충전 안내가 열립니다. 상단 "가입 승인" 버튼(또는 /approvals)에서 처리합니다.

  • 승인 — 신청 한 건에서 [승인]을 누릅니다. 차량 ID 칸을 비워 두면 EV-U0001 형식으로 자동 부여되고, 기존 OBD 차량과 연결하려면 그 차량 ID를 입력합니다.
  • 반려 — 사유(2자 이상)를 적고 [반려]를 누릅니다. 이용자는 모바일 화면에서 사유를 확인합니다.
  • 번호판은 가려진 값만 보이고, 목록 조회·승인·반려는 접속기록에 남습니다. 목록은 10초마다 자동 갱신되며, "전체" 탭에서 처리된 내역을 볼 수 있습니다.

16. 모바일 앱(내 차) 안내

차량 등록자는 /app(홈 화면에 추가해 앱처럼 사용 가능)에서 아래 기능을 씁니다. 기본 언어는 한국어이며 상단 KR/EN으로 바꿀 수 있습니다. 화면 속 금액·절감 효과는 가정값 기반 모의 결과입니다.

  • 충전 시간 — 출발 시각과 필요 잔량을 넣으면 추천 충전 시간과 예상 절감액을 보여 주고, 요금·예측 추세 그래프를 함께 제공합니다.
  • 방전 참여 — 기본은 꺼짐(옵트인)입니다. 켜야 방전 시간이 안내되고, "즉시 중지"로 언제든 끌 수 있으며 변경 이력은 회원정보 이력·접속기록에 남습니다.
  • 안전 확인 — 추천 계획을 최적화와 별개로 다시 검증합니다(출발 잔량·예비 잔량 20%·용량·방전 35~80% 구간·충방전 동시 금지·참여 여부). 하나라도 실패하면 방전 없는 계획으로 자동 복귀합니다.
  • 예측 — 충전 수요와 V2G 가용량 48시간 요약을 보여 줍니다.
  • 내 정보 — 상단 "내 정보"에서 내 정보 열람·정정(시·도별 시·군·구 선택), 비밀번호 변경, 동의 현황, 변경 이력, 회원 탈퇴, 반려된 신청의 다시 신청을 할 수 있습니다.
