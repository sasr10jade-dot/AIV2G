## 제 1 장. 프로젝트 개요 및 핵심 도메인 컨텍스트

### 1.1 사업 목적 및 핵심 목표
1. **서포터즈 실차 30대 전수 수급**: 토레스 EVX, EV6, 니로 EV 등 실차 30대에 OBD2 텔레메트리 단말을 장착하여 실제 충전·운행 데이터를 LTE Cat.M1 망으로 전수 수급.
2. **CPO 충전사업자 3사 150기 연계**: 나이스인프라㈜ 50기, ㈜플러그링크 50기, ㈜이브이시스 50기 충전기 트랜잭션 연계 및 관제.
3. **실증 거점 충전소 3곳 부하 모델링**:
   - **거점 1 (공공기관)**: 공공기관 청사 부설 충전소 (광주 서구 내방로 / 500kW) ➔ 피크 45.0 kW 감축
   - **거점 2 (기업빌딩)**: 기업 빌딩 부설 충전소 (전남 나주 빛가람동 / 800kW) ➔ 피크 75.0 kW 감축
   - **거점 3 (도시공용)**: 도시 공용 거점 충전소 (광주 북구 첨단과기로 / 1,200kW) ➔ 피크 110.0 kW 감축
4. **AI 충전수요 예측 및 V2G 의사결정**:
   - ㈜아크릴 조나단 GPU 인프라와 연계하여 48시간 전력수요 및 전기차 충전수요 시계열 예측.
   - 아우토크립트 HiGHS LP 최적화 엔진을 통해 계통 부하 분산 스케줄링 및 가용 방전량(kWh) 모의 추론.
   - 시간대별 한전 요금 단가 절감액을 차주 50%, 인프라사업자 30%, 플랫폼 20%로 배분하는 이익공유 정산.

### 1.2 실증 성과 표기 원칙 (절대 준수)
* **방전 설비의 현실적 전제**: 실증 차량 및 충전기에 양방향 방전 하드웨어 설비가 부재하므로, 방전은 **실측 충전·운행 데이터를 바탕으로 AI가 소프트웨어 Closed-loop로 모의 추론**합니다.
* **실측 vs 모의 분리 원칙**: UI 및 리포트의 모든 데이터는 `[실측]`(검정 실선 배지)과 `[모의/추론]`(파란 점선 배지)으로 엄격히 분리 표기되며, 합성 데이터는 성과 실적에 산입하지 않습니다.

## 제 2 장. 시스템 아키텍처 및 최신 화면 형상

### 2.1 관리자 웹 화면 (LNB 사이드바 일체형 구조)
대시보드(`/dashboard`), 가입 승인(`/approvals`), 웹앱 관리(`/admin`) 3개 관리자 화면 전체가 완벽하게 통일된 엔터프라이즈 레이아웃을 공유합니다.

```
+--------------------------+-----------------------------------------------------------------------------------------------+
| [좌측 LNB 사이드바]        | [상단 탑 바 (Top Bar)]                                                                        |
|                          | [☰ 메뉴]        [새로고침] [자동새로고침] [가이드] [다크] [KR] [admin(최고관리자)] [계정관리] [로그아웃]  |
| [AX·V2G 허브 실증]  [◀]  | +---------------------------------------------------------------------------------------------+
|                          | [우측 메인 컨텐츠 영역]                                                                       |
|  [ 운영 대시보드 ]         |  - [핵심 요약] 카드 (성과지표 요약, 결과 엑셀 다운로드)                                       |
|    가입 승인             |  - 01 실증 인프라: 데이터 현황판 (수집 속도 막대차트, 첫 화면 하단 칼맞춤)                    |
|    웹앱 관리             |  - 01 실증 인프라: 참여 거점 3곳 리스트 및 CPO 150기 관제 리스트 (필터/검색 지원)             |
|    API 안내              |  - 01 공개 데이터: 도시 전력수요 및 재생에너지 발전량 차트                                    |
|                          |  - 02 AI 예측: 예측 정확도(실제 vs 예측) & 충전수요 전망 차트 (2분할)                         |
|  EV 30/30                |  - 03 V2G 효과검증: 일반 충전 vs AI 최적화 시간대별 충전량 차트 & 효용성 검증                  |
|  충전기 150/150          |  - 04 이익공유: 3자 배분 시뮬레이션 및 월별 환원금액 표                                       |
|  데이터 4,000건+         |                                                                                               |
+--------------------------+-----------------------------------------------------------------------------------------------+
```

1. **좌측 LNB 사이드바 (`.ax-sidebar`)**:
   - `AX·V2G 허브 실증` (로고, V1.0 삭제 완료)
   - `운영 대시보드` (`/dashboard`), `가입 승인` (`/approvals`), `웹앱 관리` (`/admin`), `API 안내` (`/docs`)
   - 하단 실증 인프라 상태 알약 칩 (`EV 30/30`, `충전기 150/150`, `데이터 현황`)
   - **사이드바 숨김/열기 토글**: 로고 옆 `[◀]` 버튼 및 상단 탑바 `[☰ 메뉴]` 버튼으로 접힘/열림 토글. 디폴트는 **열림(230px)**이며 `localStorage`에 상태가 보존됨. GPU 가속 `transform: translateX(-100%)` 및 `0.28s cubic-bezier(0.25, 1, 0.5, 1)` 프리미엄 슬라이딩 적용.
2. **상단 탑 바 (`.ax-topbar`)**:
   - 도구 버튼군 일괄 우측 정렬: `새로고침`, `▶ 자동 새로고침`, `이용 가이드`, `다크 모드` 스위치, `KR/EN`, `admin (최고관리자)` 배지, `계정관리`, `로그아웃`.
3. **대시보드 차트 규격 188px 일괄 통일**:
   - 대시보드 내 5개 주요 차트(수집속도, 재생에너지, 예측정확도, 충전수요전망, 최적화비교) 높이를 **`height: 188.0px`** 단일 규격으로 일괄 통일.
   - 첫 진입 시(Above the Fold) 스크롤 없이 데이터 현황판 차트 바닥이 첫 화면 하단에 칼같이 안착.
   - 바 차트 범례 및 고대비 색상 일치화: 충전 세션(코발트 네이비 `#1B3B78`), 차량-일(스카이 블루 `#60A5FA`).
   - 불필요했던 "모의 데이터 조건 설정 (데모용)" 카드 및 시나리오 조작 로직 완전 삭제.
4. **CPO 150기 관제 리스트 탑재**:
   - 01 인프라 탭에 CPO 3사별 150기 충전기 현황 테이블(나이스인프라 50기, 플러그링크 50기, 이브이시스 50기, 급속/완속 필터 및 실시간 검색 지원).

### 2.2 모바일 서포터즈 앱 (`/app`, PWA)
1. **상단 헤더**: 좌측 `AX·V2G` 텍스트 로고(AX 아이콘 배지 삭제 완료), 우측 `[KR | EN]` + `다크모드` + `내 정보` + `로그아웃` 한 줄 정돈.
2. **PWA 설치 배너**: `홈 화면에 추가하면 앱처럼 쓸 수 있어요.` 1줄 슬림 배너.
3. **회원가입**: 시·도 ➔ 시·군·구 ➔ **동·읍·면**까지 드롭다운 선택 지원 (`config/regions.json` dongs 연동).
4. **거주지 맞춤 추천 충전소 알림**:
   - 가입 거주지(`sigungu`, `dong`)를 자동 판별하여 모바일 알림함 최상단에 **"📍 [거주지 맞춤] 추천 충전소 안내"** 자동 발송 (광주 서구 ➔ 거점1 시청, 나주 ➔ 거점2 한전거리, 광주 북구/첨단 ➔ 거점3 첨단산단).
5. **충전기록 탭**: 상단 지표 토글(`[충전량][횟수][요금]`)과 기간 토글(`[일][주][월]`) 가로 1행 컴팩트 정돈.

### 2.3 개발자 진입점 (`/dev`)
- PC 대시보드 카드에 **`⚡ 최고관리자로 열기`** 원클릭 로그인 버튼 제공 (`super_admin` 세션 즉시 발급).
