### 문서화 단계 메모 (요청 반영, 2026-10-22)

- 산출물: **기능정의서.docx**, **서비스정의서.docx** — "AI V2G 개발 소스 기준".
- 소스에서 뽑아야 정확하므로 수작업으로 쓰지 않고 생성 스크립트(`scripts/build_spec_docs.py`)로 만든다:
  FastAPI의 OpenAPI(엔드포인트·입출력·권한), 모듈 독스트링, 설정 파일(`config/*.json`), 테스트 목록에서 추출.
- **구현된 기능만 '구현'으로 표기**하고, 예정·가정값(verified=false)·모의 결과는 구분해서 적는다.
- 기능정의서: 기능 ID·이름·설명·화면/API·입력·출력·권한·관련 소스·테스트·상태.
  서비스정의서: 서비스 개요·사용자(차량 등록자/관리자)·서비스 흐름·화면 구성·데이터·개인정보 처리·운영 정책·제약 사항.
- 형식 관련 확인은 문서 생성 직전에 한다(제출 양식이 있는지, 기존 요구사항정의서(xlsx)와 ID 체계를 맞출지).

## 결정 사항

- **모집 신청 항목**: 휴대전화번호·방문 지역(시·군·구) 필수, 차종·희망 시간대 선택. 번호판·이름은 설치기사가 현장에서
  자동차등록증으로 확인해 입력한다(개인정보 최소 수집).
- **본인 확인**: 문자 인증번호. 개발 단계는 모의 발송, 실제 발송은 문자 업체 계약 후 연동.
- **문화상품권**: 시범 모드. 포인트 교환 신청 → PC에서 관리자가 상품권 코드를 입력(암호화 저장) → 모바일 쿠폰함으로 전달.
  자동 발급 API 연동 없음.
- **직업군 5종**(회사원·자영업·주부·학생·기타), **거주지는 시·군·구까지**, **차량 승인은 PC 관리자**.
- 개인정보는 최소 수집·기본 마스킹·열람 기록. 번호판은 암호문+블라인드 인덱스로만 저장.

## 확인이 필요한 사항 (코드로 해결할 수 없음)

1. **문화상품권 지급 ↔ 사업계획서**: 계획서에는 인센티브가 "실금 정산 아님"으로 적혀 있다. 상품권은 실제 금전적 보상이므로
   지자체·사업 담당과 협의하고 계획서 문구를 맞춰야 한다. 5만 원 초과 경품의 세금(원천징수) 처리도 확인 필요.
2. **접속기록 보관 기간**: 검색 결과에서 1년/2년이 엇갈렸다. 안전성 확보조치 기준 원문으로 확정(설정값, 기본은 길게).
3. **암호화·비밀번호 저장 세부 기준, 열람 요구 처리 기한**: 원문 확인 필요.
4. **2026년 개정 개인정보 보호법**(2026-09-11 시행 보도): 유출 의심 시 72시간 내 통지 등 — 법무 확인 후 대응 문서 확정.
5. **개인정보 보호책임자(CPO) 성명·연락처**, 처리방침의 위탁·제3자 제공 항목(문자 업체 등) — 운영 주체가 정해야 함.
6. **차종별 배터리 용량·V2G 지원 여부**(`config/vehicle_models.json`, verified=false), **소모품 교체 주기**(제조사 지침서).
7. **OBD 설치 사업자 계약·설치기사 배정 방식**, 방문 설치 시 개인정보 취급 위탁 여부.
8. **공공데이터 인증키**(공공데이터포털 활용신청: 환경공단 충전소 정보, 전력거래소 SMP·지역별 발전량), **한전 전력데이터 개방포털 인증키**,
   **기상청 API허브 키**. 개발 단계도 심의 승인이 필요해 바로 발급되지 않을 수 있다(`kpx_ingest.py` 주석 참고). 각 API의 요청·응답
   명세는 연동 직전에 공식 문서로 다시 확인한다(Swagger 위젯이라 자동 수집이 어려운 경우가 있음).

## 알려진 한계·후속 과제

- **PII 키 교체·재암호화 도구 없음**: `PII_KEY`가 유출되면 번호판 암호문이 보호되지 않는다. 교체 시 재암호화 스크립트가 필요하다.
- ~~로그인·비밀번호 변경 시도 횟수 제한 없음~~ → 2026-10-23 추가(`src/auth/throttle.py`: 계정 8회·IP 40회, 10분 잠금). 메모리 기반이라 다중 프로세스 배치 시 공유 저장소로 옮겨야 한다.
- **외부 공개 시**: `SESSION_HTTPS_ONLY=1`(Secure 쿠키·HSTS), `TRUST_PROXY_HEADERS=1`(프록시의 실제 접속지)을 설정하고, 개발용 간편 로그인(`DEMO_*`)·최고관리자 부트스트랩 환경변수는 끈다(`scripts/run_public_demo.py` 참고).
- **접속 IP**: 프록시 뒤에 배치하면 프록시 주소가 기록된다(배포 구조 확정 후 확인).
