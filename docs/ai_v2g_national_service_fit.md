# AI-V2G 대국민 서비스 전략안 — 이번 실증사업 적합성 진단

대상: 「피지컬 AI 시대의 AI-V2G 대국민 서비스 구축 전략」(국가 PnC 기반, ISO/IEC 42001 연계) 제안 문안.
기준: 현재 저장소 구현(2026-10-22). 구현 여부는 코드·테스트 기준이며, 가정값(`verified=false`)은 구분한다.

## 1. 한 줄 판단

전략안의 **"경제성보다 이동권·배터리 안전 우선", "사용자가 언제든 방전을 끌 수 있음", "순편익(보상−추가 전력비−열화비)으로 검증"** 은
이번 실증(충전 시간 안내·V2G 모의·이용자 모바일웹)과 **정확히 맞고 바로 개발 가능**하다.
반면 **ISO 15118-20·V2G PKI·전력시장 정산·VPP 운영·자율주행 충전**은 인증기관·충전기 제조사·시장 제도가 선행 조건이라
이번 소프트웨어 실증 범위 밖이다(문서·로드맵 수준으로 다룬다).

## 2. 항목별 적합성

| 전략안 항목 | 현재 구현 | 적합성 | 판단·다음 작업 |
|---|---|---|---|
| ① AI 자동 충전·요금 절감 (출발 시각·필요 잔량 입력) | 충전 시간 안내(`/owner/charging-guide`), 잔량 상태변수 MILP(`soc_planner`), 즉시충전 대비 절감 | **높음 · 구현** | 유지. 실요금 연동은 한전 키 발급 후(D2) |
| ② 방전 참여·보상, 배터리 보호 우선 | 방전 허용 범위 35~80%, 예비 20%, 열화비·손익분기 반영, 모의 보상 | **높음 · 구현(모의)** | 보상은 가정값 — 제도·계약 확정 전까지 "실제 정산 아님" 표기 유지 |
| 사용자 조건 위반 방전 금지 (예: 08시 출발·최소 70%) | 최적화 제약 + **이번에 독립 안전 검증 추가**(`safety_guard`) | **높음 · 이번 구현** | 검증 실패 시 방전 없는 계획으로 자동 복귀, 결과를 화면에 표시 |
| 방전 참여 철회·즉시 중지 | **이번에 추가**: `/owner/consent/v2g`, 기본 꺼짐, 변경 이력·접속기록 | **높음 · 이번 구현** | 모바일 "켜기/즉시 중지" 스위치 |
| ③ 개인 맞춤 에너지 관리(이동패턴·이력) | 차량 프로필·충전 안내·내 충전 리포트 | 중간 | 이동패턴 학습은 데이터(OBD 수집) 축적 후. 지금은 입력형 |
| ④ V2H·비상전원 | 없음 | 낮음 | 별도 기능·안전요건. 이번 범위 제외, 로드맵에만 명시 |
| ⑤ 피지컬 AI 자율 충전 | 없음 | 낮음(미래) | 제외. 4단계 비전으로만 서술 |
| ⑥ VPP·분산에너지 | 군집 최적화(`optimize_fleet`), 수요 예측, 나주 태양광 연계 에뮬 | 중간 | 시뮬레이션 수준으로 실증 가능(피크 감축 kW·가용 MW 산출). 실제 VPP 운영은 제외 |
| PnC·PKI·ISO 15118-20 | OCPP 보안 문서만 있음(`docs/ocpp_security.md`) | 낮음(외부 의존) | 인증서·충전기 필요. 소프트웨어로는 인터페이스 정의·시험 시나리오 문서까지 |
| ISO/IEC 42001 체계 | 일부 증거가 이미 있음(아래 3절) | **중간 · 문서화로 확보 가능** | 위험평가서·영향평가서·KPI를 저장소 기능에서 뽑아 정리 |
| 순편익 KPI(보상−추가 전력비−열화) | `cost`에 방전수익·열화비·절감액 분리 표시 | **높음 · 구현** | 실증 KPI 화면에 순편익 집계 추가 가능 |

## 3. ISO/IEC 42001 조항 ↔ 이미 있는 증거

| 조항 | 요구 | 현재 증거 | 부족한 것 |
|---|---|---|---|
| 6.1.2 AI 위험평가 | 과도한 방전·잘못된 예측·부당한 추천 | 방전 범위·예비 잔량 제약, 예측 `verified=false` 표기 | 위험평가서 문서 |
| 6.1.3 위험처리 | 최소 SoC·방전 한도·수동 중단 | **`safety_guard` 독립 검증, 방전 참여 스위치(이번)** | 위험처리계획 문서 |
| 6.1.4 AI 영향평가 | 경제적 손실·이동권·개인정보 | 개인정보 보호 점검표(`owner_web_roadmap.md`), 모의 결과 표기 | 영향평가서 |
| 8장 운영 | 모델 검증·변경·재평가, 운영 로그 | 모델 레지스트리, 해시체인 감사로그, 테스트 591건 | 추천 결과 로그(입력·검증 결과) 보존 |
| 9장 성과평가 | 예측오류·민원·보상정확도 KPI | `kpi.py`, 예측 평가 | 예측오류·위험통제 준수율 KPI 지표 정의 |
| 5장·10장 | 책임 지정, 시정조치 | 유출 대응 문서(`privacy_incident_response.md`) | RACI, 시정조치 양식 |

주의: 42001은 AI 관리체계 표준이며 차량 전기적 안전을 인증하지 않는다(전략안도 같은 입장). 문서에서 "인증 취득"이 아니라
"체계 정합성 확보"로 표현해야 한다.

## 4. 이번에 구현한 것 (안전·이동권 우선)

1. `src/advisory/safety_guard.py` — 계획을 최적화기와 별개 코드로 재검증(출발 잔량·예비 잔량·용량·방전 범위·동시 충방전·참여 여부).
   하나라도 실패하면 방전 없는 계획(V1G)으로 되돌리고 `safety.fallback=true`로 알린다.
2. 방전 참여 스위치 — `GET/PUT /owner/consent/v2g`. **기본 꺼짐(명시적으로 켜야 방전 안내)**, 켜고 끄는 이력은 회원정보 이력·접속기록에 남는다.
3. 모바일 화면 — 방전 참여 카드(켜기/즉시 중지), 안전 확인 카드(항목별 통과 표시).
4. 테스트 — 위반 유형별 검증기 단위 테스트, 기본 꺼짐·즉시 중지 동작, 권한 격리.

## 5. 다음 개발 후보 (우선순위)

1. **추천·안전 검증 결과 로그**(42001 8장): 입력·추천·검증 결과를 해시체인 로그에 저장, 운영 화면에서 조회.
2. **실증 KPI 보강**: 순편익(보상−추가 전력비−열화), 위험통제 준수율, 예측오차, 방전 참여 철회율.
3. **VPP 시뮬레이션 지표**: 참여 차량 합산 피크 감축 kW·가용 MW(나주 태양광 연계 에뮬과 결합).
4. **AI 위험평가서·영향평가서·RACI 초안**: 위 증거를 근거로 문서 생성(기능정의서 생성 스크립트와 같은 방식).
5. 외부 선행 조건 필요: PnC·PKI·15118-20 시험 환경, 전력시장 정산·보상 단가 확정, 한전·공공데이터 API 키.

## 6. 사업계획서 문구 주의

- "경제적 이익"은 **가정값 기반 모의**임을 유지한다(현재 화면·응답에 `verified=false`·"실제 정산 아님" 표기).
- 방전 참여는 **동의(옵트인)·철회 가능**임을 명시하면 개인정보·이동권 측면에서 설득력이 높다.
- V2H, 자율주행 충전, 전국 VPP는 "확장 비전"으로 분리하고 이번 실증 KPI에 넣지 않는다.
