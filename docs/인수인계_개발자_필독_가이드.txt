================================================================================
AI-V2G 실증 시스템 개발자 인수인계 퀵스타트 가이드 (Quick Start)
================================================================================

본 소스 코드는 GitHub 원격 저장소(sasr10jade-dot/AIV2G)의 최신 'main' 브랜치
(Commit: dd09d03)와 100% 일치하는 클린 소스 트리입니다.

임시 캐시(__pycache__, .pytest_cache)와 불필요한 파일이 완벽히 정제되어 있으며,
USB 전달 및 신규 개발 환경 셋업에 즉시 사용할 수 있습니다.

--------------------------------------------------------------------------------
1. 주요 디렉터리 구성
--------------------------------------------------------------------------------
- docs/          : [필독] 개발자 인수인계서, PRD, 데이터 명세서(엑셀 3종 및 MD), 계획서 PDF
- src/           : FastAPI 백엔드 라우터, LP 최적화 엔진, 정적 프론트엔드(static/)
- config/        : CPO 3사 연계, 공공 API, 요금표, 거주지 행정동 설정 JSON
- data/          : SQLite 데이터베이스 및 계정 정보 (curated.db, users.json)
- scripts/       : CPO 동기화, 실차 OBD 배치, 데이터 수급 파이프라인 자동화 스크립트
- tests/         : 단위 및 통합 테스트 스위트 (pytest 80+ 케이스)
- android/       : 서포터즈 모바일 TWA 안드로이드 앱 빌드 프로젝트
- downloads/     : 빌드 완료된 서포터즈 APK (AIV2G-supporter-1.1.0.apk)

--------------------------------------------------------------------------------
2. 개발 환경 셋업 및 로컬 서버 구동 (Windows PowerShell / Linux 공통)
--------------------------------------------------------------------------------
[1단계] 가상환경 생성 및 의존성 패키지 설치
  python -m venv venv
  .\venv\Scripts\activate          # (Linux: source venv/bin/activate)
  pip install -r requirements.txt

[2단계] 환경변수 파일 생성
  copy .env.example .env           # (Linux: cp .env.example .env)
  * .env.example에 개발용 기본 자격증명이 세팅되어 있어 별도 수정 없이 즉시 실행 가능합니다.

[3단계] 로컬 FastAPI Uvicorn 서버 기동
  python -m uvicorn src.api.main:app --host 127.0.0.1 --port 8000 --reload

[4단계] 브라우저 접속 확인
  - 개발자 진입점 (추천): http://127.0.0.1:8000/dev
    * '⚡ 최고관리자로 열기' 버튼을 누르면 아이디/비밀번호 입력 없이 즉시 로그인됩니다.
  - PC 운영 대시보드 : http://127.0.0.1:8000/dashboard
  - 가입 승인 관리   : http://127.0.0.1:8000/approvals
  - 웹앱 관리 (어드민) : http://127.0.0.1:8000/admin
  - 모바일 서포터즈 앱: http://127.0.0.1:8000/app
  - 대화형 API 문서  : http://127.0.0.1:8000/docs

--------------------------------------------------------------------------------

--------------------------------------------------------------------------------
