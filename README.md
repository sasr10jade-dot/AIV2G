# AI-V2G 실증 시스템 — 먼저 읽기

올인원 AI 허브 AX 실증(에너지·모빌리티) **AI-V2G** 과제의 개발 소스다.
서포터즈 EV 차량 OBD·충전사업자(CPO) 충전 세션·공공데이터를 모아 실증 데이터셋을 만들고,
시간대별 EV 충전수요를 예측해 차량별 충전(·V2G 방전) 시간을 추천하고, VPP 모의 정산까지 하는 웹·앱 시스템이다.

- 기준일: 2026-11-25 (기준 커밋은 `git log -1`)
- 원본 저장소: https://github.com/sasr10jade-dot/AIV2G (main)
- 스택: Python 3.14 · FastAPI · SQLite · LightGBM · pandas / 화면 `src/api/static` / 안드로이드 TWA `android/`
- 테스트: `pytest` 593개 통과(3개 skip)

## 2. 바로 실행 (Windows, 내 PC)

```
python -m venv venv
.\venv\Scripts\activate
pip install -r requirements-dev.txt
copy .env.example .env
python -m uvicorn src.api:app --host 127.0.0.1 --port 5050 --reload
python -m pytest -q
```

`data/`가 비어 있어도 된다 — 첫 실행 때 DB를 만들고, 실측 데이터가 없으면 **합성(모의) 데이터**로 모든 화면이 돈다
(화면·API 응답에 `is_real_data=false` / `data_source=synthetic`으로 표시). 예측 모델도 없으면 첫 요청 때 기준 모델을 학습한다.

## 3. 현재 상태 (2026-11-25)

**구현 완료**
- 수집: OBD 배치(`scripts/run_obd_batch.py`), CPO 3사 어댑터·푸시 수신·충전 인증 태그 결합, 공공데이터 연계 코드
- 실증 데이터셋: 1건 = 이벤트(운행·차량 충전·거점 충전) × [① 차량·충전기 블록 + ② AI 학습 블록] (`src/pipeline/dataset.py`)
- 예측: 시간대별 EV 충전수요(주)·가용 배터리(보조), LightGBM 기준 모델 + 아크릴 예측 수신·오차 비교
- 최적화·추천: 차량별 충전·방전 계획(안전 검증 포함), 추천 근거 설명(Claude API, 키 없으면 문장 틀)
- VPP 모의 정산·포인트·미션, 서포터즈 가입·승인·예비 참여자, 동의·해시체인 감사로그·가명처리
- 배치: **주간 재학습**(월 05:00, `kr.aiv2g.retrain`), **일 배치**(매일 04:30, `kr.aiv2g.daily` — 데이터 결합→예측 갱신→아크릴 오차→차량별 추천)

**아직 아닌 것(이어서 할 일)**
1. **실측 데이터 연계 시작** — 지금 모든 데이터는 합성. CPO·KPX·공공데이터포털·아크릴·TOAST 키/계약이 등록되면 같은 코드가 실측으로 돈다(키는 `.env`, 서버에서는 설정 여부만 확인).
2. **예측 정확도** — 합성 데이터 기준 1−WAPE 66.2%로 목표 70% 미달. 실측 데이터로 재평가·튜닝 필요. 아크릴 모델 미수신.
3. **기상 예보 연계** — 미래 시점 외부 변수(기온 등)를 합성 패턴으로 채우고 있음(`src/model/forecast_service.py` forecast_horizon).
4. **V2G 최적화 입력** — 차량 계획이 예측값이 아니라 관측 데이터 기반. 실증 차량이 모두 V2G 미지원이라 방전은 추론값.
5. **대시보드 절감액 단가** — 계통 신호 가격 기준. KEPCO EV 요금표 기준으로 바꿀지 결정 대기.
6. **사업 일정 입력 대기** — 13주 수집 기간, 주간 운행 횟수 d, 마일스톤 4개 날짜(`config/data_plan.json`).

## 4. 이 패키지에서 뺀 것

| 항목 | 이유 | 받는 방법 |
|---|---|---|
| `.env` | API 키·비밀 값 | `.env.example`을 복사해 담당자에게 키를 받아 입력 |
| `data/` | 서포터즈 개인정보 DB, 가명·암호화 키 | 필요하면 책임자 승인 후 별도 전달. 없으면 자동 생성 |
| `output/`, `downloads/`, 캐시 | 실행 로그·내려받은 APK·재생성 가능 | 실행하면 다시 생김 |

## 5. 지켜야 할 것

- 개발 서버(192.168.35.92)의 **다른 서비스 포트(80, 5000, 8000/8443, 8080, 8090, 7000, 5173, 49152)는 절대 건드리지 않는다.** 이 시스템은 5050(HTTP)·5443(HTTPS)만 쓴다.
- 5050·5443은 **사내망 전용** — 포트포워딩·터널로 외부에 열지 않는다.
- 키 값은 문서·커밋·로그에 쓰지 않는다. 개인정보(번호판 등)는 암호화·가명 처리 경로로만 다룬다.
